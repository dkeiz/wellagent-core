# Wellagent Core

**The intelligence engine powering your local AI agents.**

Wellagent Core is the headless brain behind the Wellagent ecosystem. It manages everything your AI agents need to think, remember, and act on your behalf—all while keeping your data strictly private.

## Capabilities

- **Universal AI Support**: Connects to OpenAI, Anthropic, Ollama, LM Studio, and OpenRouter.
- **Persistent Memory**: Gives agents the ability to remember past conversations and preferences.
- **Real-World Actions**: Equips agents with tools to search the web, read files, and run commands.
- **Absolute Privacy**: Runs entirely locally; only communicates with explicitly authorized services.

## Ecosystem

You do not need to install the core directly to use Wellagent. Instead, install an app powered by this engine:

- [Wellagent Desktop](https://github.com/dkeiz/wellagent-desktop) — The graphical app for Windows, Mac, and Linux.
- [Wellagent Companion](https://github.com/dkeiz/wellagent-companion) — Connect with your agents on the go.
- [Wellbot](https://github.com/dkeiz/wellbot) — A command-line interface.

*(For developers: See the [API Documentation](src/README.md) to build custom agents).*
